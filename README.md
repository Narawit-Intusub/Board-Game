# Modular Smart LED Matrix (กระดานไฟ LED อัจฉริยะต่อขยายได้อิสระสำหรับระบบเกมกระดาน)

---

## 1. ภาพรวมโปรเจกต์ (Project Overview)

**Modular Smart LED Matrix** คือ กระดานแสดงผลไฟ LED อัจฉริยะแบบต่อขยายได้อิสระ (Modular Interactive Grid) ออกแบบมาเพื่อเป็นกระดานเล่นเกมแบบ Interactive (Interactive Tabletop Gaming Grid) และหน้าจอแสดงผลกราฟิกแบบปรับเปลี่ยนรูปทรงได้ 

แต่ละแผ่นกระดานสามารถนำมาแปะติดกันด้วย **ขั้วต่อแม่เหล็ก (Magnetic Pogo Pin)** ในทิศทางใดก็ได้ (เหนือ, ใต้, ตะวันออก, ตะวันตก) โดยระบบจะทำการ:
* **ตรวจจับโครงสร้างอัตโนมัติ (Topology & Auto-Discovery):** ทราบทันทีว่ามีบอร์ดใดมาต่ออยู่ที่ตำแหน่งใด ทรงอะไร
* **สลับเส้นทางสัญญาณข้อมูลความเร็วสูง (Hardware Auto-Routing):** สลับทิศทาง Data In / Data Out ให้ข้อมูลไฟวิ่งต่อเนื่องไร้รอยต่อ
* **สร้างผืนหน้าจอแสดงผลเกมผืนเดียวกัน (Unified 2D Coordinate Grid):** รวมกระดานหลายแผ่นให้เป็นพื้นที่แสดงผลพิกัด $(X, Y)$ ผืนเดียวแบบเรียลไทม์

```
     +---------------+
     |  Slave Board  | (ต่อขยายด้านบน)
     +-------+-------+
             | [ขั้วต่อแม่เหล็ก]
+------------+---+---------------+---------------+
|  Master Board  |  Slave Board  |  Slave Board  | (ต่อขยายแนวยาว หรือรูปตัว L)
|   (ESP32 MCU)  | (ATtiny1604)  | (ATtiny1604)  |
+----------------+---------------+---------------+
```

## 2. การแสดงผลระบบเกมบนกระดาน (Game Mechanics & Visual Effects)

ระบบฮาร์ดแวร์ถูกออกแบบมาเพื่อรองรับกลไกเกมกระดานแนววางแผน (Turn-based Strategy / TTRPG / Tactical Board Game) โดยแสดงผลเอฟเฟกต์ไฟแบบเรียลไทม์ 60 FPS ได้อย่างสมบูรณ์แบบ:

```
  [ Fog of War ]       [ Movement Range ]       [ Laser Piercing Beam ]
  (ช่องมืดสนิท)          (สีน้ำเงิน/เขียวอ่อน)       =======(แสงวิ่งทะลุแถว)======>
        ░░                    ████
        ░░                 ██ [ P ] ██          [ Ice ]          [ Lava ]
        ░░                    ████              (ฟ้าคราม)        (แดงหายใจช้าๆ)
```

### 2.1 กลไกการเล่นและเอฟเฟกต์แสงไฟ
1. **ระยะการเดิน (Movement Range):**
   * **เมื่อเลือกตัวละคร:** ช่องที่ตัวละครยืนอยู่จะกะพริบเป็นจังหวะหายใจ (**Pulse สีขาว**)
   * **พื้นที่เดินได้ (Move Stat):** ช่องตารางรอบตัวละครตามระยะก้าวจะสว่างขึ้นเป็น **สีน้ำเงิน หรือ เขียวอ่อน** บอกขอบเขตที่สามารถเดินไปได้ แม้พื้นที่เดินจะล้นข้ามรอยต่อไปยังบอร์ดลูกข้างๆ ไฟก็จะสว่างเชื่อมกันอย่างไร้รอยต่อ
2. **ระยะการโจมตีธรรมดา (Attack Range):**
   * ช่องของศัตรูที่อยู่ในระยะโจมตี จะกะพริบเตือนเป็น **สีแดงเข้ม (Flashing Dark Red)** เพื่อระบุเป้าหมายที่เลือกโจมตีได้
3. **ระยะสกิลและพื้นที่ผลกระทบ (Skill & Area of Effect - AoE):**
   * **สกิลโจมตีหมู่ (Fireball / Explosion):** ไฮไลต์พื้นที่ระเบิดเป็นสี่เหลี่ยม $2 \times 2$ หรือรูปกากบาทด้วย **สีส้ม-แดง (Orange-Red)** หากจุดศูนย์กลางอยู่ตรงขอบบอร์ด สะเก็ดระเบิดจะแผ่ข้ามไปยังบอร์ดข้างเคียงทันที
   * **สกิลบัฟ / ฟื้นฟูพลัง (Heal Aura):** แสดงวงแหวนแสง **สีเขียวสว่าง หรือ สีเหลืองทอง** แผ่คลื่นรอบตัวผู้ร่ายสกิล
   * **แนวกระสุนทะลวงเส้นตรง (Laser / Arrow Line):** แสดงลำแสงไฟวิ่งพุ่งเป็นเส้นตรงผ่านแถวของกระดานข้ามแผ่นต่อเนื่องไม่มีสะดุด
4. **สถานะพื้นที่และอันตราย (Terrain & Hazard Effects):**
   * **ช่องน้ำแข็ง (Ice / Slow):** สว่างนิ่งเป็น **สีฟ้าคราม (Cyan)** บอกพื้นที่ลดความเร็วการเคลื่อนที่
   * **ช่องลาวา (Lava / Hazard):** สว่างวาบเป็น **สีแดงแบบหายใจช้าๆ (Red Breathing Pulse)** เตือนอันตราย Damage over turn
   * **หมอกควันแห่งสงคราม (Fog of War):** พื้นที่ที่ยังไม่ได้สำรวจจะ **ดับไฟมืดสนิท (Black / LEDs OFF)** และจะค่อยๆ สว่างเปิดแผนที่ (Reveal) เมื่อตัวละครเดินเข้าไปในระยะการมองเห็น

## 3. สถาปัตยกรรมระบบฮาร์ดแวร์ (Hardware Architecture)

ระบบแบ่งออกเป็น 2 ประเภทบอร์ด ทำงานสอดประสานกันอย่างมีประสิทธิภาพ:

```
+-------------------------------------------------------------------------------+
|                             Master Board (ESP32)                              |
|  - Game Engine & Logic: คำนวณกฎเกม, ระยะเดิน, พื้นที่ AoE, หมอกควัน              |
|  - Frame Renderer: เรนเดอร์สีของทุกพิกเซลส่งออกเป็น WS2812B Data Stream (800kHz)|
|  - Level Shifter (74AHCT1G125): แปลงระดับสัญญาณจาก 3.3V เป็น 5.0V              |
|  - Local Display: แผงไฟ 64 LEDs (MOD1 - MOD16)                                 |
+---------------------------------------+---------------------------------------+
                                        | ขั้วต่อแม่เหล็ก 4 ทิศ (DOUT, SENSE, +5V, GND)
                                        v
+-------------------------------------------------------------------------------+
|                     Slave Expansion Board (ATtiny1604)                        |
|  - Neighbor Detection: ATtiny1604 ตรวจจับทิศทางที่มีบอร์ดมาเสียบต่อรอบ 4 ด้าน  |
|  - Hardware Auto-Routing: สั่งชิป 74HC153 MUX สับรางเลือกรับ Data จากทิศนั้น   |
|  - Zero-Latency Passthrough: ส่งข้อมูลผ่าน Buffer 74AHCT1G125 เข้าไฟ 64 LEDs   |
|  - Daisy-Chain Out: ส่งข้อมูลส่วนที่เหลือออกไปยังขอบด้านอื่น ๆ เพื่อต่อบอร์ดถัดไป |
+-------------------------------------------------------------------------------+
```

### 3.1 บอร์ดแม่ (Master Controller Board - ESP32)
* **สมองส่วนกลาง:** ใช้โมดูล **ESP32** ประมวลผลตรรกะของเกมและควบคุมการแสดงผล มีการเชื่อมต่อไร้สาย (Wi-Fi / Bluetooth) เพื่อรับคำสั่งจากสมาร์ตโฟนหรือคอมพิวเตอร์
* **การขับสัญญาณไฟ:** ใช้ไอซี **74AHCT1G125 Level Shifter** แปลงแรงดันจาก 3.3V เป็น 5.0V เพื่อให้สัญญาณข้อมูลเข้าสู่หลอดไฟ WS2812B ได้อย่างถูกต้อง แม่นยำ และไม่มีสัญญาณรบกวน
* **รายละเอียดเพิ่มเติม:** อ่านได้ที่ [hardware/master/README.md](hardware/master/README.md)

### 3.2 บอร์ดลูก (Slave Expansion Board - ATtiny1604 + 74HC153)
* **ไมโครคอนโทรลเลอร์ประจำบอร์ด (ATtiny1604):** ทำหน้าที่เป็น "ผู้จัดการการเชื่อมต่อ" คอยอ่านสถานะพิน Sense รอบทิศ และสั่งการสลับทางสัญญาณข้อมูล
* **ชิปสลับสายข้อมูลฮาร์ดแวร์ (74HC153 Multiplexer):** รับหน้าที่สลับเลือกรับสัญญาณ Data In จาก 1 ใน 4 ทิศทาง ด้วยความหน่วงระดับนาโนวินาที (~10ns) ทำให้สัญญาณแสงวิ่งผ่านได้ด้วยความเร็วแสง
* **รายละเอียดเพิ่มเติม:** อ่านได้ที่ [hardware/slave/README.md](hardware/slave/README.md)

## 4. สรุปเหตุผลการเลือกใช้อุปกรณ์สำคัญ (Design Rationales)

### 4.1 ทำไมต้องเลือกใช้ ATtiny1604 บนบอร์ดลูก?
1. **ทำงานที่ไฟเลี้ยง 5.0V ได้โดยตรง:** ไม่จำเป็นต้องมีไอซีลดแรงดัน 3.3V LDO บนบอร์ดลูก ลดจำนวนอุปกรณ์ ลดความร้อน และประหยัดพื้นที่ PCB
2. **ขนาดกะทัดรัดและราคาประหยัด:** แพ็กเกจ SOIC-14 มีต้นทุนต่ำ เหมาะสำหรับการผลิตบอร์ดลูกในปริมาณมาก
3. **จำนวนขา I/O พอดี (12 ขา ใช้ 9 ขา):** รองรับ 4 Sense, 3 MUX Control, 1 LED Status และ 1 UPDI Data
4. **ระบบ UPDI Single-Wire:** โปรแกรมชิปได้โดยใช้สายสัญญาณเพียงเส้นเดียว ทำให้หัวต่อโปรแกรมมีขนาดเล็กมาก

### 4.2 ทำไมต้องมี Multiplexer (74HC153)?
1. **จุดรับข้อมูลของ LED มีจุดเดียว:** บอร์ดสามารถต่อได้ 4 ทิศทาง แต่พิน Data In ของหลอดไฟมีทางเข้าเดียว จึงต้องมีสวิตช์เลือกช่องทางเข้า
2. **ป้องกันสัญญาณชนกันและสัญญาณสะท้อน (Isolation):** หากนำสาย 4 ทิศมารวบต่อกันตรงๆ ขอบที่ไม่ได้เสียบจะกลายเป็นเสาอากาศรับสัญญาณรบกวนและสะท้อนคลื่นกลับทำให้ไฟกระพริบเพี้ยน ชิป MUX จะตัดขาดขอบที่ไม่ใช้งานออก 100%
3. **ความหน่วงแทบเป็นศูนย์ (Zero Latency):** สัญญาณผ่าน MUX ในเวลาเพียง ~10-15 ns โดยไม่ต้องให้ MCU มาคอยส่งต่อด้วยซอฟต์แวร์ ทำให้ ESP32 สามารถยิงเฟรมเรตแอนิเมชันได้สูงถึง 60 FPS

## 5. กลไกการเชื่อมต่อแม่เหล็ก (Magnetic Pogo Pin Interface)

ขอบกระดานทั้ง 4 ทิศใช้ขั้วต่อแม่เหล็ก 4 ขา ออกแบบการจัดวางแบบ **Poka-Yoke (ป้องกันการต่อกลับด้าน)**:
* ขอบ **North และ East** ใช้ขั้วต่อ **ตัวเมีย (Female)**
* ขอบ **South และ West** ใช้ขั้วต่อ **ตัวผู้ (Male)**

```
  Female Connector (North / East)       Male Connector (South / West)
      +---------------------+               +---------------------+
      | (1)  (2)  (3)  (4)  |               | (1)  (2)  (3)  (4)  |
      | GND SENSE DATA +5V  |               | +5V DATA SENSE GND  |
      +---------------------+               +---------------------+
```

* **การประกบกันแบบ 180° Inversion:** เมื่อนำขอบ Female มาชนกับ Male พิน +5V จะตรงกับ +5V, GND ตรงกับ GND, SENSE ตรงกับ SENSE และ DATA IN ตรงกับ DATA OUT โดยอัตโนมัติ
* **โครงข่ายจ่ายพลังงานร่วมกัน (Power Bus):** พิน +5V และ GND เชื่อมต่อถึงกันทุกขอบ ทำให้เมื่อเสียบไฟ 5V ที่บอร์ดใด บอร์ดข้างเคียงจะได้รับไฟเลี้ยงไปด้วยทันที
