# Slave Expansion Board (บอร์ดลูก) - Modular Smart LED Matrix

เอกสารนี้อธิบายรายละเอียดการออกแบบทางฮาร์ดแวร์ หน้าที่ของแต่ละชิ้นส่วน เหตุผลในการเลือกใช้ชิป **ATtiny1604** การทำงานของวงจร Auto-Routing ด้วย **74HC153 Multiplexer** และการเชื่อมต่อผ่าน **Magnetic Connectors** สำหรับ **Slave Expansion Board** (ไฟล์ KiCad: [Slave_Matrix_4x4.kicad_sch](Slave_Matrix_4x4.kicad_sch)) ไว้อย่างละเอียดครบถ้วน

---

## 1. ภาพรวมบอร์ดลูก (Slave Board Overview)

**Slave Expansion Board** คือ "กระดานไฟส่วนขยาย" ที่ออกแบบมาเพื่อนำไปต่อเพิ่มพื้นที่แสดงผลกับบอร์ดแม่ (Master) หรือต่อพ่วงกับบอร์ดลูกตัวอื่น ๆ ได้อย่างอิสระทั้ง 4 ทิศทาง (เหนือ, ใต้, ออก, ตก) 

ความท้าทายของระบบ Modular ที่ต่อขยายได้อิสระคือ: **"ผู้ใช้อาจนำบอร์ดมาเสียบต่อเข้าทางด้านใดก็ได้ ทำให้สัญญาณ Data In อาจวิ่งเข้ามาจากทิศเหนือ ทิศใต้ ทิศตะวันออก หรือทิศตะวันตก ก็ได้"**

บอร์ดลูกจึงได้รับการออกแบบให้มี **ระบบกำหนดเส้นทางสัญญาณอัตโนมัติ (Autonomous Signal Auto-Routing)** ในตัว โดยมีไมโครคอนโทรลเลอร์ **ATtiny1604** คอยตรวจจับทิศทางการเชื่อมต่อ และสั่งการให้ชิปสลับสัญญาณข้อมูล (**74HC153 Multiplexer**) ดึงสัญญาณไฟจากขอบด้านที่ถูกต้องเข้าสู่ไฟ LED 64 ดวงในบอร์ด แล้วส่งต่อออกไปยังขอบด้านอื่น ๆ โดยอัตโนมัติ

```
+-----------------------------------------------------------------------------------+
|                           Slave Expansion Board                                   |
|                                                                                   |
|                        [ J_NORTH (Female Mag-4P) ]                                |
|                        (DATA_N, SENSE_N, +5V, GND)                                |
|                                     |                                             |
|                                     v                                             |
|  [ J_WEST (Male) ]  <--->   +---------------+   <--->  [ J_EAST (Female) ]        |
|  (DATA_W, SENSE_W)          |   74HC153     |          (DATA_E, SENSE_E)          |
|                             |  Multiplexer  |                                     |
|                             +-------+-------+                                     |
|                                     | 1Y (Selected Data)                          |
|         +---------------+           v                                             |
|         |  ATtiny1604   | ---> [ 74AHCT1G125 ] Buffer                             |
|         |  Controller   |           | DIN_LOCAL                                   |
|         +-------+-------+           v                                             |
|                 |           +---------------+                                     |
|                 v           |  LED Matrix   | (MOD1 -> MOD2 -> ... MOD16)         |
|             [ LED D1 ]      |  (64 LEDs)    |                                     |
|             Status Green    +-------+-------+                                     |
|                                     | DOUT_LOCAL                                  |
|                                     v                                             |
|                        [ J_SOUTH (Male Mag-4P) ]                                  |
|                        (DATA_S, SENSE_S, +5V, GND)                                |
+-----------------------------------------------------------------------------------+
```

## 2. ทำไมถึงเลือกใช้ ATtiny1604 และมีหน้าที่ทำอะไร?

### 2.1 เหตุผลหลักในการเลือกใช้ ATtiny1604 (Why ATtiny1604?)

1. **ทำงานที่แรงดัน 5.0V โดยตรง (Native 5V Operation):**
   - ชิปในตระกูล AVR 0-Series อย่าง ATtiny1604 รองรับไฟเลี้ยงกว้างตั้งแต่ **1.8V ถึง 5.5V**
   - ทำให้สามารถรับไฟ 5V จากบัสไฟหลักของระบบได้โดยตรง **โดยไม่ต้องเพิ่มไอซีลดแรงดัน (3.3V LDO Voltage Regulator) บนบอร์ดลูก** ช่วยลดจำนวนอุปกรณ์ (BOM Count), ลดความร้อนสะสม และประหยัดพื้นที่บนแผ่น PCB
2. **ขนาดเล็กและราคาประหยัด (Ultra-Compact & Cost-Effective):**
   - ตัวถังเป็นแพ็กเกจ **SOIC-14** (หรือ QFN-20) ใช้พื้นที่บนบอร์ดน้อยมาก และมีราคาต่อหน่วยต่ำ เหมาะสำหรับบอร์ดลูกที่ต้องผลิตจำนวนมาก
3. **จำนวนขา I/O เหมาะสมพอดีกับการใช้งาน (Optimized Pin Utilization):**
   - ชิปมีขา I/O ทั้งหมด 12 ขา ซึ่งในวงจรนี้ถูกใช้งาน 9 ขาได้อย่างคุ้มค่าพอดี:
     - **4 ขา** สำหรับ Sense ตรวจจับบอร์ดเพื่อนบ้านรอบทิศ (`SENSE_N`, `SENSE_E`, `SENSE_S`, `SENSE_W`)
     - **3 ขา** สำหรับควบคุมเส้นทางชิป Multiplexer (`MUX_S0`, `MUX_S1`, `MUX_EN`)
     - **1 ขา** สำหรับขับไฟ LED แสดงสถานะ (`LED_STATUS`)
     - **1 ขา** สำหรับโปรแกรม/ดีบักแบบสายเดียว (`UPDI_DATA`)
4. **ระบบโปรแกรมแบบสายเดียว (Single-Wire UPDI Interface):**
   - การโปรแกรมเฟิร์มแวร์ใช้โปรโตคอล UPDI (Unified Program and Debug Interface) ซึ่งใช้สายสัญญาณเพียง **1 เส้น** (พิน `PA0`) ทำให้ใช้หัวต่อโปรแกรม (`J_PROG`) ขนาดเพียง 3 ขา (VCC, UPDI, GND) ลดขนาดพื้นที่ Header บนบอร์ด
5. **สถาปัตยกรรมทันสมัยและประหยัดพลังงาน (Modern AVR 0-Series Architecture):**
   - มี Flash Memory 16KB, SRAM 1KB, Internal Oscillator 20MHz ไม่ต้องต่อ Crystal ภายนอก และมีระบบ Brown-out Detection (BOD) ในตัว ช่วยให้ระบบเสถียรเมื่อมีการกระชากของกระแสไฟ

---

### 2.2 หน้าที่ของ ATtiny1604 ในบอร์ดลูก (Role & Responsibilities)

1. **การตรวจจับทิศทางสัญญาณเข้า (Input Neighbor Detection):**
   - อ่านระดับสัญญาณลอจิกจากพินขอบแม่เหล็กทั้ง 4 ทิศ (`SENSE_N`, `SENSE_E`, `SENSE_S`, `SENSE_W`) โดยใช้ตัวต้านทาน Pull-up ภายในชิป
   - เมื่อมีบอร์ดแม่หรือบอร์ดลูกอื่นมาประกบ พิน Sense ด้านนั้นจะเปลี่ยนสถานะ ทำให้ ATtiny1604 ทราบทันทีว่าสัญญาณ Data วิ่งเข้ามาจากทิศใด
2. **การสลับเส้นทางส่งข้อมูล (Multiplexer Address Switching):**
   - ส่งสัญญาณลอจิกไปยังขา `MUX_S0` (PB0), `MUX_S1` (PB1), และ `MUX_EN` (PB2) เพื่อควบคุมไอซี **74HC153** ให้ต่อสายสัญญาณข้อมูลจากด้านที่ตรวจพบเข้าสู่เมทริกซ์ไฟของบอร์ดตัวเอง
3. **การแสดงผลสถานะการทำงาน (Visual Status Indication):**
   - ควบคุมหลอดไฟ LED สีเขียว (`D1`) ผ่านขา `LED_STATUS` (PB3):
     - ไฟติดสว่าง / กระพริบตามจังหวะ เพื่อบอกว่าบอร์ดกำลังทำงานปกติ ตรวจพบเพื่อนบ้านแล้ว หรืออยู่ในโหมด Standby

## 4. กลไกการสลับสัญญาณข้อมูลอัตโนมัติ (Auto-Routing via 74HC153)

ชิป **74HC153** เป็นไอซีประเภท 4-Channel Multiplexer โดยในวงจรนี้เราใช้ Channel 1 เป็นตัวเลือกรับสัญญาณไฟเข้า:

```
  DATA_N (North) ----> Pin 6 (1I0) ---\
  DATA_E (East)  ----> Pin 5 (1I1) ----+---> [ 74HC153 ] ---> Pin 7 (1Y) ---> [ U3 Buffer ] ---> DIN_LOCAL
  DATA_S (South) ----> Pin 4 (1I2) ----+
  DATA_W (West)  ----> Pin 3 (1I3) ---/
                              ^
                              | MUX_S0, MUX_S1, MUX_EN
                      +-------+-------+
                      |  ATtiny1604   |
                      +---------------+
```

### ตารางการควบคุมเส้นทาง (Multiplexer Truth Table):
| MUX_EN (`PB2`) | MUX_S1 (`PB1`) | MUX_S0 (`PB0`) | แหล่งสัญญาณที่เลือก (Selected Input) | ทิศทางที่สัญญาณเข้า | สัญญาณส่งออก 1Y |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **0 (LOW)** | **0** | **0** | **1I0** | **ทิศเหนือ (North)** | ส่ง `DATA_N` เข้า LED |
| **0 (LOW)** | **0** | **1** | **1I1** | **ทิศตะวันออก (East)** | ส่ง `DATA_E` เข้า LED |
| **0 (LOW)** | **1** | **0** | **1I2** | **ทิศใต้ (South)** | ส่ง `DATA_S` เข้า LED |
| **0 (LOW)** | **1** | **1** | **1I3** | **ทิศตะวันตก (West)** | ส่ง `DATA_W` เข้า LED |
| **1 (HIGH)** | X | X | ไม่มี | ตัดการเชื่อมต่อ (Disabled) | เอาต์พุตเป็น LOW |

> **หมายเหตุ:** ขา `2~E` (Pin 15) ของ Channel 2 ต่อไว้ที่ `+5V` เพื่อปิดการทำงานส่วนที่ไม่ได้ใช้งาน ป้องกันสัญญาณลอย (Floating Input)

## 5. การทำงานของ Magnetic Connectors (ขั้วต่อแม่เหล็ก 4 ทิศ)

ขั้วต่อแม่เหล็กเป็นอินเทอร์เฟซหลักในการเชื่อมต่อระหว่างบอร์ด มี 4 พินต่อทิศทาง:

```
  Female Connector (North / East)       Male Connector (South / West)
      +---------------------+               +---------------------+
      | (1)  (2)  (3)  (4)  |               | (1)  (2)  (3)  (4)  |
      | GND SENSE DATA +5V  |               | +5V DATA SENSE GND  |
      +---------------------+               +---------------------+
```

### ตารางการจับคู่ขาสัญญาณแม่เหล็ก (Magnetic Pinout Map):
| Pin # | North (`J_NORTH`) Female | East (`J_EAST`) Female | South (`J_SOUTH`) Male | West (`J_WEST`) Male | หน้าที่ของสัญญาณ |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **1** | `GND` | `GND` | `+5V` | `+5V` | ไฟเลี้ยงระบบ / กราวด์อ้างอิง |
| **2** | `SENSE_N` | `SENSE_E` | `DATA_S` | `DATA_W` | สัญญาณตรวจจับ หรือ สัญญาณข้อมูลสี |
| **3** | `DATA_N` | `DATA_E` | `SENSE_S` | `SENSE_W` | สัญญาณข้อมูลสี หรือ สัญญาณตรวจจับ |
| **4** | `+5V` | `+5V` | `GND` | `GND` | ไฟเลี้ยงระบบ / กราวด์อ้างอิง |

### หลักการส่งสัญญาณและตรวจจับ (Signaling & Sense Mechanism):
1. **การจ่ายไฟร่วมกัน (Power Sharing Bus):** ขั้ว `+5V` และ `GND` ของทุกคอนเนคเตอร์ถูกต่อเชื่อมเข้าหากันเป็นโครงข่ายบัสพลังงาน ทำให้เมื่อจ่ายไฟที่บอร์ดใดบอร์ดหนึ่ง กระแสไฟจะวิ่งกระจายไปยังบอร์ดข้างเคียงผ่านพินแม่เหล็กโดยอัตโนมัติ
2. **การตรวจจับทิศทาง (Neighbor Handshake/Sense):**
   - พิน Sense ของแต่ละด้านต่อเข้ากับขา ADC/GPIO ของ ATtiny1604 (`PA1..PA4`)
   - เมื่อไม่มีการเชื่อมต่อ ขา Sense จะถูกดึงเป็น HIGH ด้วย Internal Pull-up ของ MCU
   - เมื่อนำบอร์ดอื่นมาประกบ ขา Sense จะถูกต่อเข้ากับฝั่งตรงข้าม ทำให้แรงดันเปลี่ยนหรือเกิดการตรวจจับสัญญาณ handshake ATtiny1604 จะรับรู้และทำการสั่ง MUX ให้เปิดทิศนั้นทันที
3. **การส่งต่อข้อมูล (Data Daisy-Chaining):**
   - สัญญาณเข้าผ่าน MUX -> ผ่าน Buffer `U3` -> เข้า `MOD1 (IN)`
   - วิ่งวนครบ 64 หลอด (MOD1 ถึง MOD16) ออกที่ `MOD16 (OUT)` ซึ่งเชื่อมต่อเป็น `DOUT_LOCAL` ไปยังคอนเนคเตอร์ด้านที่เหลือเพื่อส่งต่อไปยังบอร์ดลูกถัดไป

## 7. การเบิร์นเฟิร์มแวร์ลง ATtiny1604 (Programming Guide)

สามารถใช้ USB-to-UART Adapter ทั่วไป หรือโปรแกรมเมอร์ UPDI (เช่น SerialUPDI, jtag2updi, หรือ Atmel-ICE) ต่อเข้าที่ขั้ว `J_PROG`:

```
   [ Programmer UPDI ]                   [ Slave Board J_PROG ]
   +-----------------+                   +--------------------+
   |       VCC       | ----------------> |  Pin 1: +5V        |
   |    UPDI / TX+RX | ----------------> |  Pin 2: UPDI_DATA  |
   |       GND       | ----------------> |  Pin 3: GND        |
   +-----------------+                   +--------------------+
```

* แนะนำให้พัฒนาด้วย **megaTinyCore** บน Arduino IDE หรือ PlatformIO
* ตั้งค่า Clock เป็น **Internal 16MHz หรือ 20MHz** (ไม่ต้องใช้ Crystal ภายนอก)
* ตั้งค่า BOD (Brown-out Detector) ไว้ที่ 4.2V หรือ 2.6V เพื่อความปลอดภัย
