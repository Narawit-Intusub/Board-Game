# Master Controller Board (บอร์ดแม่) - Modular Smart LED Matrix

เอกสารนี้อธิบายรายละเอียดการออกแบบทางฮาร์ดแวร์ บล็อกการทำงาน หน้าที่ของแต่ละโมดูล/ชิ้นส่วน การเชื่อมต่อสัญญาณ และหลักการทำงานของ **Master Controller Board** (ไฟล์ KiCad: [Master_Matrix_4x4.kicad_sch](Master_Matrix_4x4.kicad_sch)) อย่างครบถ้วน เพื่อให้ผู้พัฒนาหรือผู้นำไปสร้างต่อสามารถเข้าใจและนำไปใช้งานได้อย่างถูกต้อง

---

## 1. ภาพรวมบอร์ดแม่ (Master Board Overview)

**Master Controller Board** คือ "สมองส่วนกลาง" ของระบบกระดานไฟ LED อัจฉริยะแบบต่อขยายได้ (Modular Smart LED Matrix) 
มีหน้าที่หลัก 4 ประการ:
1. **ศูนย์กลางประมวลผลและสร้างภาพ (Graphics & Animation Engine):** รับคำสั่ง/ข้อมูลภาพผ่าน Wi-Fi หรือ Bluetooth และคำนวณตำแหน่งพิกเซล (X, Y) สำหรับการแสดงผลบนเมทริกซ์ทั้งหมด
2. **การตรวจจับบอร์ดลูกรอบทิศ (Topology & Neighbor Discovery):** ตรวจจับว่ามีบอร์ดลูก (Slave) มาเชื่อมต่อที่ขอบด้านใดบ้าง (North, South, East, West) ผ่านพินตรวจสอบ (Sense/Detect Pins)
3. **การส่งข้อมูลพิกเซลความเร็วสูง (High-Speed LED Data Transmission):** แปลงสัญญาณข้อมูลสี 800 kHz จากระดับแรงดัน 3.3V เป็น 5.0V แล้วส่งเข้าสู่ Matrix ไฟบนบอร์ดตัวเอง และส่งต่อไปยังบอร์ดลูกผ่านขั้วต่อแม่เหล็ก
4. **การแสดงผลในตัว (Local Display):** มีแผงไฟ LED RGB Addressable (WS2812B/SK6812) จำนวน 64 หลอด จัดเรียงแบบ 4x4 โมดูล (ขนาดทางกายภาพ 8x8 LEDs) ในตัว

```
+-------------------------------------------------------------------------+
|                        Master Controller Board                          |
|                                                                         |
|                     [ J_NORTH (Female Mag-4P) ]                         |
|                                  ^                                      |
|                                  | (DOUT, SENSE_N, +5V, GND)            |
|                                  v                                      |
|  [ J_WEST (Male) ] <---  +---------------+  ---> [ J_EAST (Female) ]    |
|                          |   ESP32 MCU   |                              |
|                          |  DevKit V1    |                              |
|                          +-------+-------+                              |
|                                  | GPIO18 (3.3V Data)                   |
|                                  v                                      |
|                          [ 74AHCT1G125 ] Level Shifter                  |
|                                  | DIN (5.0V Data via 330R)             |
|                                  v                                      |
|                          +---------------+                              |
|                          |  LED Matrix   | (MOD1 -> MOD2 -> ... MOD16)  |
|                          |  (64 LEDs)    |                              |
|                          +-------+-------+                              |
|                                  | DOUT                                 |
|                                  v                                      |
|                     [ J_SOUTH (Male Mag-4P) ]                           |
+-------------------------------------------------------------------------+
```

## 3. รายละเอียดการทำงานของวงจรสำคัญ

### 3.1 วงจรแปลงระดับสัญญาณ (Level Shifter Circuit - 74AHCT1G125)
* **ปัญหาที่ต้องแก้:** ขา GPIO ของ ESP32 จ่ายสัญญาณ Logic HIGH ที่ **3.3V** แต่หลอด WS2812B/SK6812 ที่ทำงานที่ไฟเลี้ยง 5.0V ต้องการแรงดัน $V_{IH}$ (Input High Voltage) ขั้นต่ำที่ $0.7 \times V_{DD} = 3.5\text{V}$ หากต่อตรงโดยไม่แปลงระดับ สัญญาณไฟอาจกระพริบ เพี้ยน หรือไม่ทำงานเมื่อสายยาวขึ้นหรืออุณหภูมิเปลี่ยน
* **การทำงานของ 74AHCT1G125:**
  - เลือกรุ่นตระกูล **AHCT** เพราะมี $V_{IH}$ ขั้นต่ำเพียง **2.0V** ที่ไฟเลี้ยง 5V (TTL-compatible) จึงสามารถรับสัญญาณ 3.3V จาก ESP32 ได้อย่างสมบูรณ์แบบ
  - ขา Output จ่ายสัญญาณ Swing เต็มที่ **0V ถึง 5.0V** พร้อมความเร็วในการสลับสัญญาณสูงถึง 100+ MHz (สัญญาณ WS2812B วิ่งที่ 800 kHz)
  - ขา `~OE` (Pin 1) ต่อลง GND เพื่อ Enable เอาต์พุตไว้ตลอดเวลา

```
  ESP32 (GPIO18) --------> [ Pin 2 (A) ]
                              74AHCT1G125  --------> [ Pin 4 (Y) ] ---> [ R1: 330R ] ---> DIN (เข้า MOD1)
  +5V -------------------> [ Pin 5 (VCC) ]
  GND -------------------> [ Pin 1 (~OE), Pin 3 (GND) ]
```

---

### 3.2 วงจรแสดงผล LED Matrix 4x4 (MOD1 - MOD16)
บอร์ดแม่ประกอบด้วยโมดูล **CJMCU-2812-4** จำนวน 16 ตัว เชื่อมต่อกันแบบ **Daisy-Chain** (ข้อมูลไหลต่อเนื่องแบบงูกินหาง / Serpentine หรือ Raster):

```
 แถว 1:  DIN ---> [MOD1] ---> [MOD2] ---> [MOD3] ---> [MOD4]
                                                         |
 แถว 2:           [MOD8] <--- [MOD7] <--- [MOD6] <--- [MOD5] <---+
                    |
 แถว 3:  +--------> [MOD9] ---> [MOD10] ---> [MOD11] ---> [MOD12]
                                                            |
 แถว 4:          [MOD16] <--- [MOD15] <--- [MOD14] <--- [MOD13] <---+
                    |
                    +---> DOUT (ส่งต่อไปยัง Connector แม่เหล็กทุกด้าน)
```

* แต่ละโมดูลมี 4 หลอด LED (2x2) ดังนั้นใน 1 แถวของโมดูล (4 โมดูล) จะมีไฟ 8 หลอด
* 16 โมดูลรวมกัน = 64 หลอด LED
* สัญญาณขาออกสุดท้ายจาก `MOD16 (OUT)` จะเป็นสัญญาณ `DOUT` ที่ถูก Re-timing และชดเชยระดับแรงดันโดยอัตโนมัติจากชิป WS2812B ตัวสุดท้าย พร้อมส่งต่อไปยังบอร์ดลูกตัวถัดไป

---

### 3.3 การทำงานของ Magnetic Connectors (ขั้วต่อแม่เหล็ก 4 ทิศ)

ขั้วต่อขอบเป็นหัวต่อแบบแม่เหล็กพร้อมพินสปริง (Magnetic Pogo Pin Connector) 4 ขา ออกแบบมาเพื่อความสะดวกในการแปะต่อ ไม่ต้องเสียบสาย และป้องกันการต่อกลับด้าน

```
  Female Connector (North / East)       Male Connector (South / West)
      +---------------------+               +---------------------+
      | (1)  (2)  (3)  (4)  |               | (1)  (2)  (3)  (4)  |
      | GND SENSE DATA +5V  |               | +5V DATA SENSE GND  |
      +---------------------+               +---------------------+
```

#### ตารางนิยามขาสัญญาณของขั้วต่อแม่เหล็ก (Pin Assignment):
| Pin # | North Connector (`J_NORTH`) Female | East Connector (`J_EAST`) Female | South Connector (`J_SOUTH`) Male | West Connector (`J_WEST`) Male | หน้าที่ของสัญญาณ |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **1** | `GND` | `GND` | `+5V` | `+5V` | ไฟเลี้ยงระบบ / กราวด์อ้างอิง |
| **2** | `D01` (SENSE_N) | `D11` (SENSE_E) | `DOUT` (Data Out) | `DOUT` (Data Out) | สัญญาณตรวจจับ หรือ สัญญาณข้อมูลสี |
| **3** | `DOUT` (Data Out) | `DOUT` (Data Out) | `D21` (SENSE_S) | `D31` (SENSE_W) | สัญญาณข้อมูลสี หรือ สัญญาณตรวจจับ |
| **4** | `+5V` | `+5V` | `GND` | `GND` | ไฟเลี้ยงระบบ / กราวด์อ้างอิง |

#### กลไกความปลอดภัยและการจับคู่แบบสมมาตร (Mechanical & Electrical Symmetry):
* **ป้องกันการกลับขั้ว (Poka-Yoke):** ขอบ North/East ใช้หัวตัวเมีย (Female) ขอบ South/West ใช้หัวตัวผู้ (Male) เมื่อนำบอร์ดสองแผ่นมาชนกัน (เช่น North ของบอร์ดหนึ่ง ชนกับ South ของอีกบอร์ดหนึ่ง) พินจะประกบกันแบบ 180° Inversion:
  - Pin 1 (GND) จะตรงกับ Pin 4 (GND)
  - Pin 2 (SENSE) จะตรงกับ Pin 3 (SENSE)
  - Pin 3 (DOUT) จะตรงกับ Pin 2 (DATA IN ของบอร์ดลูก)
  - Pin 4 (+5V) จะตรงกับ Pin 1 (+5V)
* **กลไกการตรวจจับเพื่อนบ้าน (Neighbor Auto-Discovery):**
  - ขา `D01` (ESP32 IO26), `D11` (ESP32 IO14), `D21` (ESP32 IO13), `D31` (ESP32 IO33) ตั้งโหมดเป็น Input with Pull-up ใน ESP32
  - เมื่อบอร์ดลูกมาต่อ ขาสัญญาณ Sense จะถูกดึงแรงดันลงหรือเกิดการส่งสัญญาณ Handshake ทำให้ ESP32 ทราบทันทีว่ามีบอร์ดลูกเชื่อมต่ออยู่ที่ทิศใด

## 5. ข้อแนะนำในการประกอบและทดสอบ (Assembly & Testing Tips)

1. **การจ่ายไฟ (Power Delivery):**
   - เมื่อเปิดไฟ LED สีขาวสว่างสูงสุดทั้ง 64 หลอด บอร์ดแม่จะกินกระแสประมาณ $64 \times 60\text{mA} = 3.84\text{A}$
   - ควรจ่ายไฟ 5V ผ่านทาง `J_PWR` (Terminal Block) ด้วยสายไฟที่มีขนาดอย่างน้อย 18-20 AWG
2. **การบัดกรีโมดูล LED:**
   - วางโมดูล CJMCU-2812-4 ให้ลูกศรชี้ทิศทางของ Data Out ตรงตามผัง Daisy Chain เพื่อป้องกันข้อมูลไม่ไหล
3. **การตรวจสอบสัญญาณ:**
   - ทดสอบวัดสัญญาณที่ขา 4 ของ `U2` ด้วย Oscilloscope ควรเห็น Pulse สัญญาณความกว้างประมาณ 0.4µs / 0.8µs ที่แรงดัน 5.0V สวยงามไม่มี Overshoot รุนแรง
